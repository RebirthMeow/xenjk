# Slow-approach drops: bot_moveDropSlow

Recorded 2026-09-24. Open item 1 of the
[circle record](2026-09-24-circle-runup.md): at Force Speed every drop off
Dantooine's upper walkway carries past the narrow floor below into the hurt
water pit, and the planner reroutes to sibling drops on the same wall seven
times (`blue_out_L2_stand` class 150, +3,400 ms under the circle).

## The change

`bot_moveDropSlow` (u/s; 150 unless set, 0 off; default since the adoption below). `PlannedSearch`, `bot2_move.c`:
a drop edge whose 12 full-speed candidates all fail is searched again, once,
with 15 more:

- the same three headings and four takeoff offsets, the run-up and the flight
  asking for the approach speed along the heading instead of the speed there
  is (the controller brakes to it on the ground, and in the air it holds it
  with no strafe gain);
- a step off along each heading: no tap; leaving the ground is the launch,
  and a run-up that covers 64 units past the edge's takeoff still grounded is
  a miss (`no_ledge`).

Two plan fields carry it (`approach`, `stepOff` in `bot2_movePlan_t`); the
executor (`HopStep`) and the measure (`SpikeMeasure`, the step-off launch)
read them, so the forecast judges each slow candidate by the same executor
it would run live. Full-speed drops that admit anything are unchanged, and
every other edge type is untouched. `[SPIKE]` lines gain `approach` and
`step_off`; the commit event gains the same two fields.

## Results

Build `dropslow-build-20260924-a`, production settings, library off, both arms
on the same build (`bot_moveDropSlow` 0 against 150),
`.codex-research/dropslow-20260924-a/` (`dropslow-20260924-a.sh`).

**The named case** (`.codex-research/dropslow-probe-20260924-a/`):
`blue_out_L2_stand` class 150, 18,225 → **15,525 ms**. Control: drop edges 20,
24, 21, 17, 16, 28 each searched twice and failed, edge 29 admitted on the
seventh. Slow: edge 20, the first drop, admitted on its first search
(27 candidates, 15 admitted, a 150 u/s tap committed).

**Dantooine v3, pinned**, levels 1-2, classes 50 and 150, matched pairs
(class misses before release excluded):

Mirrored cases give identical times in every pair. The changed pairs are all
worlds where a slow drop was committed: `blue_out`/`red_ret_L2_stand` class
150 -2,700 each, `*_L2_stand` class 150 -175 twice, class 50 level 1 -700
twice and +275 twice, class 50 level 2 +175 twice. Of 34 slow commits across
the campaign, 19 were taps and 15 step-offs.

**Kejim**, red stand, levels 1-2, classes 75-150, one world a cell: all eight
cells identical in both arms (L2 8,350 / 10,125 / 9,875 / 10,125; L1 11,650 /
15,925 / 14,325 / 16,525), and identical to the circle record's library-off
row. No Kejim drop search failed, so no slow candidate was rolled out.

**Floors, slow 150**: Kejim, ctf4, Dantooine v3 **36/36 each, zero deaths**.
Level totals (unpinned, one pass) against the circle floors
(`circle-20260924-c`): Kejim 192.2 / 125.6 / 124.5 s against 183.8 / 117.0 /
118.5; ctf4 249.1 / 177.8 / 172.8 against 253.0 / 176.7 / 174.3; Dantooine
236.8 / 167.0 / 168.4 against 233.3 / 171.9 / 167.8. The Kejim floor rolled out
no slow candidate either, so its difference is unpinned world variance on an
unchanged code path; ctf4 rolled 48 slow candidates and committed none;
Dantooine committed slow drops in 8 worlds.

**Cost** is not measured separately. The slow pass adds 15 rollouts, and only
after a drop search has admitted nothing, which the control repeated seven
times on the named case.

cases shared with `dant-c150-slow150`.

## Open

- Rerouting to sibling drops into the same hazard (circle record item 2) is
  not needed for this case; it stays unbuilt unless a gap remains.
- 150 u/s is the single value tried.
- Review notes (2026-09-24, no defects): a step-off's launch is recorded on the
  first airborne frame, so `l0_speed`/`launch0` are one frame into the air and
  `flightFrames` is one short of a tap's; any airborne frame of a step-off
  run-up (a stair lip) counts as the launch, which the judge then rejects as
  `off_path` when it lands back on the upper floor; the Kejim floor's +8 s at
  level 1 rolled no slow candidate and is unpinned variance, so the floor
  totals do not measure the switch.
