# xenjk_showcase map

An original model-showcase map, generated by script and compiled with q3map2. It uses only stock JKA assets and its
own two flat studio textures.

- **Deck:** a floating Cloud City deck under the stock Bespin sunset sky. The low warm sun is the model's front-left
  key; there is a mauve sky fill and amber pylon strips behind the stage. The live sun (`q3gl2_sun`) gives
  rd-vulkan/rend2 cascaded shadows.
- **Studio:** a grey cyclorama with key, fill, two rims and a backdrop light. Reach it from the blue pad on the deck;
  the pad in the studio corner goes back.

Build (needs the q3map2 of netradiant-custom 20260114, named by the environment variable `Q3MAP2`; a full build takes
about 10 s):

```
python tools/showcase_map/build_showcase_map.py [--fast] [--out DIR]
```

Screenshots in the installed client (hidden, muted, private homepath, nothing installed):

```
python tools/showcase_map/look.py DIR/zz_xenjk_showcase.pk3 [--model jan] [--set "r_sunShadows 0"]
```

In game: `devmap xenjk_showcase`, then `exec xenjk_showcase` for the front-facing third-person camera
(`cg_thirdPersonAngle` orbits the model).

Lighting values are constants at the top of `build_showcase_map.py`. Studio lights are in `studio()`.

Rejected base: rgoer's "Sunset on Coruscant" (`rgoer_duel2`, 2004). Its readme says "This map cannot be used as a
base for any other map", and it ships no `.map` source. The owner chose an original map instead (2026-10-13).
